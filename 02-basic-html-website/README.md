# Project: Basic HTML Website

## Description
In this project, you are required to create a simple HTML-only website with multiple pages. The website should have the following pages:

    - Homepage
    - Projects
    - Articles
    - Contact

The website should have a navigation bar that should be present on all pages and link to all the pages.

## Goal

The goals of this project are:

- [x] Learn how to create multiple pages on a website.
- [x] Structure a website semantically using HTML.
- [x] Structure in a way that you can easily add styles later.
- [x] Add SEO meta tags to the website.
